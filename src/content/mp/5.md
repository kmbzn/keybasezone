## Topics

## Structure of ARM Assembly Code

## Syntax of Assembly
- 기본 구문 규칙
  - 레이블 문장은 라벨 명칭 뒤에 콜론 기호 없이 레이블 정의 형태로 배치
  - 기타 문장은 줄바꿈 문자로 종료
  - 지시어 Directives 마침표 기호로 시작
- 주석 Comments
  - 한 줄 주석 기호 C 스타일 double slash 사용
  - 어셈블리 전용 주석 기호 at mark 사용
  - 다중 줄 주석 slash asterisk 사용

## Assembly Expressions
- 어셈블러가 평가하는 수식 표현
- 상수 Constant 표현
  - 10진수 정수
  - 16진수 정수 0x 접두사 사용
  - 8진수 정수 0 접두사 사용
  - 2진수 정수 0b 접두사 사용
  - 음수 표현 단항 연산자 minus 사용
- 기호 참조 Symbol References
  - 수식 내 기호 사용 가능
  - 마침표 기호는 출력 파일 내 현재 위치를 나타내는 특수 기호

## Operators
- 단항 연산자 plus minus tilde
- 이항 연산자 산술 논리 비트 비교 연산자 포함

## String Definition Directives
- 현재 섹션에 문자열 리터럴 데이터 할당
- ascii 문자열 끝에 널 바이트를 추가하지 않음
- asciz 및 string 문자열 끝에 널 바이트 null terminator 자동 추가

## Data Definition Directives
- byte 1 byte
- hword 2 bytes
- word 4 bytes
- quad 8 bytes
- octa 16 bytes
- 다중 인자 지정 시 해당 크기 메모리 연속 할당 및 초기화

## Alignment Directives
- 파일의 현재 위치를 지정된 경계에 정렬
- balign 지정된 바이트 수 2의 거듭제곱 단위 정렬
- align 또는 p2align 지수 값 기준 정렬 actual boundary 2의 지수 승 바이트

## Space-filling Directives
- space count 지정된 갯수만큼 메모리 공간 할당 및 값 채움
- fill count size 지정된 크기 단위의 메모리 공간 연속 채움

## Macro Directives
- macro 및 endm 구문을 사용한 재사용 가능한 코드 블록 정의
- 매크로 인자는 백슬래시 기호를 붙여 매크로 내부에서 참조

## Org Directives
- org 현재 섹션의 위치 카운터를 새 위치로 전진
- 건너뛰는 위치는 기본 0 바이트로 채워짐

## Conditional Assembly Directives
- 어셈블 시점에 조건부로 코드 어셈블 수행
- `if elseif else endif` 구문 사용
- 런타임 조건 검사가 아닌 어셈블러에 의해 어셈블 시점 평가 진행

## Section Directives
- 어셈블러가 코드와 데이터를 생성하여 배치할 ELF 섹션 지정
- section 기본 지시어 외 text data rodata bss 전용 구문 제공

## Symbol Binding Directives
- global 기호 결합 범위를 전체 오브젝트 파일에 공개
- local 기호 결합 범위를 해당 파일 내부로 제한
- weak 약한 결합 기호 정의 미발견 시에도 오류 미발생 및 강한 결합 기호 존재 시 우선 적용
