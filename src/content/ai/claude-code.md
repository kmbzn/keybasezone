# Claude Code, 넌 누구니?

**Claude Code**는 Anthropic의 AI 에이전틱 코딩 도구입니다. 터미널에서 실행해 현재 프로젝트의 파일과 구조를 살펴보고, 자연어로 요청한 코드 변경을 여러 파일에 걸쳐 수행하도록 도울 수 있습니다.

단순히 코드를 제안하는 데 그치지 않고, 작업에 필요한 명령을 실행하거나 테스트 결과를 확인하는 흐름까지 지원합니다. 변경 사항을 살펴보고 승인하는 과정을 거치며 사용할 수 있어, 반복적인 수정이나 익숙하지 않은 코드베이스를 파악할 때 유용합니다.

Claude Code는 개발자의 판단을 대신하기보다 작업 속도를 높이는 도구에 가깝습니다. 생성된 코드와 실행 명령을 검토하고, 테스트와 버전 관리로 결과를 확인하는 것이 좋습니다.
