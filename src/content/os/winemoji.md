# 우분투에서 카카오톡 이모지가 깨져서, 결국 직접 고쳤다

이모지는 이제 메신저에서 거의 필수가 됐다. 짧은 답장 하나에도 이모지가 붙고, 같은 문장도 어떤 이모지를 쓰느냐에 따라 느낌이 달라진다.

나는 우분투를 사용하고 있고, 카카오톡 PC 버전은 Wine으로 실행한다. 기본적인 사용에는 큰 문제가 없었는데 이모지가 문제였다. 대화 중간에 이모지가 들어오면 네모로 깨지거나 제대로 표시되지 않았다. 사소해 보이지만 매일 카카오톡을 쓰다 보니 꽤 불편했다.

처음에는 폰트만 바꾸면 해결될 줄 알았다. 이모지 폰트를 설치해보고 Wine 설정도 만져봤지만 원하는 결과가 나오지 않았다. 결국 기존 폰트에 Wine에서 제대로 표시되는 이모지를 직접 넣는 방식으로 해결했고, 그 과정에서 만든 것이 **Winemoji**다.

Winemoji는 평소 사용하는 한글 폰트에 이모지를 추가해 Wine 환경에서도 깨지지 않도록 만들어주는 도구다. 직접 폰트를 넣어 빌드할 수도 있고, 바로 사용할 수 있도록 미리 작업한 폰트도 함께 제공한다.

현재 나눔고딕, 나눔명조, 나눔바른고딕, 프리텐다드, IBM Plex Sans KR, 주아, 도현, 해바라기, 고운돋움, 검은고딕 등 10종을 준비해뒀다. 미리 빌드된 폰트를 설치한 뒤 카카오톡 설정에서 해당 폰트를 선택하고 재시작하면 된다.

| 항목 | 내용 |
| --- | --- |
| 프로젝트 | [Winemoji](https://github.com/kmbzn/project-winemoji) |
| 용도 | Wine 환경에서 카카오톡 등 Windows 앱의 이모지 깨짐 해결 |

## 미리 빌드된 폰트 사용하기

[GitHub 저장소의 `fonts` 폴더](https://github.com/kmbzn/project-winemoji/tree/main/fonts)에서 원하는 폰트를 내려받아 사용자 폰트 폴더에 넣고 캐시를 갱신한다.

```bash
mkdir -p ~/.local/share/fonts
cp Pretendard-Regular-winemoji.ttf ~/.local/share/fonts/
fc-cache -fv
```

그다음 카카오톡에서 **설정 → 화면 → 기본 → 글씨체**로 이동해 설치한 폰트를 고른다. 카카오톡을 재시작하면 적용된다.

기존 폰트에 직접 이모지를 합치고 싶다면 저장소를 내려받아 `builder/run.sh`를 실행하면 GUI 빌더가 열린다. 명령줄에서는 저장소의 `install.sh`로 `winemoji` 명령을 설치한 뒤 `winemoji -b /path/to/font.ttf`처럼 사용할 수 있다. 자세한 사용법은 [README](https://github.com/kmbzn/project-winemoji#readme)에 정리해뒀다.

처음부터 프로젝트를 만들 생각은 없었다. 카카오톡에서 이모지가 깨지는 게 불편해서 이것저것 건드리기 시작했고, 제대로 해결한 김에 다른 사람도 쓸 수 있도록 정리해 GitHub에 공개했다.

리눅스를 쓰면서 생기는 이런 작은 불편은 검색해도 딱 맞는 해결책이 없는 경우가 많다. 이번에는 그냥 내가 쓰려고 만든 해결책이 하나의 프로젝트가 됐다.

**project-winemoji**

[GitHub에서 소스 코드와 설치 방법, 미리 빌드된 폰트를 확인할 수 있다.](https://github.com/kmbzn/project-winemoji)

> 빌더의 라이선스는 MIT지만, 빌더로 만들거나 저장소에서 내려받는 폰트 파일에는 각각 원본 폰트의 라이선스가 적용된다. 폰트를 수정하거나 재배포할 때는 해당 라이선스를 확인해야 한다.
