# GPT-6 Sol과 Luna, GPT-6 제품군 확장

OpenAI는 2026년 9월 22일 GPT-6 제품군에 **Sol**과 **Luna**를 추가했습니다. 두 모델은 앞서 공개된 GPT-6 Astra의 기술을 더 빠르고 낮은 비용으로 제공하는 데 초점을 둡니다. OpenAI는 업무 처리, 사실성, 코딩, 컴퓨터 사용과 정렬 성능의 개선을 함께 소개했습니다.

## Sol과 Luna는 어떻게 다를까

- **GPT-6 Sol**은 복잡한 업무와 코딩, 에이전트 작업처럼 더 높은 성능이 필요한 경우를 겨냥합니다.
- **GPT-6 Luna**는 속도와 비용 효율을 앞세워 일상적인 요청과 대량 처리에 적합하도록 설계됐습니다.

API 가격은 입력·출력 각 100만 토큰 기준 Sol이 **$2 / $10**, Luna가 **$0.10 / $0.50**입니다. OpenAI는 이를 이전 모델의 프로모션 가격보다 50% 낮춘 가격이라고 설명했습니다.

## 출시와 후속 업데이트

공개 당시 두 모델은 ChatGPT Work와 Codex, API에서 제공을 시작했습니다. Free와 Go 사용자는 데스크톱 앱에서 Luna를 사용할 수 있다고 안내됐습니다. API 모델명은 `gpt-6-sol`, `gpt-6-luna`입니다.

이후 9월 29일에는 Sol의 후속 모델인 **GPT-6.1 Sol**도 발표됐습니다. 따라서 현재 모델을 선택할 때는 최초 출시 소식과 함께 최신 모델 안내를 확인하는 편이 좋습니다.
