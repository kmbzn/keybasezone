# Claude Opus 5.5, 성능과 비용 효율을 함께 겨냥

Anthropic은 2026년 9월 22일 Claude 5.5 제품군의 첫 모델인 **Claude Opus 5.5**를 공개했습니다. 긴 코딩 작업과 전문 지식 업무, 에이전트 작업을 이어서 처리하는 능력을 강화했으며, Anthropic은 여러 업무에서 Fable 5.1에 준하는 성능을 더 낮은 비용으로 제공한다고 밝혔습니다.

API 표준 가격은 입력 100만 토큰당 **$4**, 출력 100만 토큰당 **$20**입니다. Opus 5보다 토큰 가격이 낮고 작업에 필요한 토큰 수도 줄어 전형적인 작업 비용을 약 40% 낮췄다는 설명입니다. 빠른 응답이 필요한 경우 Claude Code와 Claude Platform에서 Fast mode도 사용할 수 있습니다.

Opus 5.5는 Claude의 Pro, Max, Team, Enterprise 플랜과 API에서 제공됩니다. AWS, Google Cloud, Microsoft Azure에서도 이용할 수 있습니다. 높은 코딩·생물학 역량에 맞춰 사이버 보안과 생물학 분야에는 별도의 안전장치도 적용됐습니다.
