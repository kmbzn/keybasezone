# What is a Microcontroller?

## General Structure of Computer
- 4GB RAM 및 ROM이 Memory Bus에 연결
- Intel Dual Core CPU 중심 구성
- Peripheral Bus를 통해 Screen, Ethernet, USB, Voice, MP3 Music 등 연결

## Microprocessor vs Microcontroller
- Microprocessor
  - 단일 집적 회로 IC 칩 위의 CPU
  - 컴퓨터의 두뇌 역할
  - Intel AMD x86, ARM Cortex 계열
  - RAM, ROM, I/O 장치를 내장하지 않음
- Microcontroller
  - 단일 칩 위에 CPU, RAM, ROM, I/O 장치, 타이머 등을 통합 배치
  - Computer on a chip 또는 MCU
  - 범용 마이크로프로세서에 비해 성능은 낮으나 특정 응용 분야에 최적화
  - 작동 소프트웨어 펌웨어가 롬 하드웨어에 내장됨
  - 저전력 소모, 소형 크기, 저비용
