## Logic View of Memory
- 바이트 단위 주소 지정 배열
- 데이터 단위 크기
  - 8 bits = 1 byte
  - 16 bits = 2 bytes = 1 halfword
  - 32 bits = 4 bytes = 1 word
- Words
  - 32 bits 4 bytes
  - 워드의 메모리 주소는 해당 워드를 이루는 4개 바이트 중 가장 낮은 주소
  - 4의 배수 주소에 정렬 align
- Halfwords
  - 16 bits 2 bytes
  - 하프워드 메모리 주소는 해당 2개 바이트 중 가장 낮은 주소
  - 2의 배수 주소에 정렬 align

## Memory Map
- 주소 공간 레이아웃 설명
- Cortex-M3 프로세서는 총 4GB의 주소 공간을 가짐
- 물리적 메모리가 4GB인 것은 아님
- 고정 메모리 맵 고유 특징
  - 소프트웨어 포팅 용이
  - NVIC 및 MPU 등 시스템 컨트롤 공간의 메모리 위치가 모든 제품에서 동일

## Predefined Memory Map Layout
- `0x00000000` – `0x1FFFFFFF` Code 0.5GB
- `0x20000000` – `0x3FFFFFFF` SRAM 0.5GB Bit-band region 및 Alias 포함
- `0x40000000` – `0x5FFFFFFF` Peripherals 0.5GB Bit-band region 및 Alias 포함
- `0x60000000` – `0x9FFFFFFF` External RAM 1GB
- `0xA0000000` – `0xDFFFFFFF` External Device 1GB
- `0xE0000000` – `0xE00FFFFF` System Control Space SCS NVIC, MPU, SYSTICK 등
- `0xE0100000` – `0xFFFFFFFF` Vendor Specific


## Memory Access Attributes
- Bufferable 쓰기 버퍼를 통한 쓰기 동작 수행
- Cacheable 메모리 읽기 데이터를 캐시에 복사하여 향후 접근 속도 향상
- Executable 해당 메모리 영역에서 코드를 인출 및 실행 가능
- Sharable 다중 버스 마스터 간 데이터 공유 및 일관성 보장

## Default Access Permissions
- MPU 미탑재 또는 비활성화 상태 시 기본 액세스 권한 규칙 적용
- 접근 차단 발생 시 즉시 Fault Exception 차단 발생

## MPU Memory Protection Unit
- 메모리 및 I/O 접근 권한 검사 기능 제공
- 8~16개 별도 메모리 영역 지원
- 영역별 인출, 읽기, 쓰기 권한 설정 가능
- 권한 미부여 접근 발생 시 MMF Memory Management Fault 발생
- 영역 중첩 지원 Higher Region Number 우선 적용

## Bit-banding
- 단일 load store 조작으로 단일 데이터 비트에 접근 지원
- 비트 밴드 영역
  - SRAM 영역의 첫 1MB 주소 범위 `0x20000000` – `0x200FFFFF`
  - Peripheral 영역의 첫 1MB 주소 범위 `0x40000000` – `0x400FFFFF`
- Bit-band Alias 영역을 통해 접근
- Bus matrix에 의해 투명하게 변환 처리

## Bit-Band Operation Advantages
- 적은 명령어 수로 빠른 비트 연산 가능
- 비트 수정 시 경쟁 조건 Race Condition 방지 Atomic 연산 지원
- C 언어에서의 사용
  - 매크로를 정의하여 비트 밴드 앨리어스 주소 매핑 및 간편 조작 수행

## Unaligned Transfers
- 비정렬 이송 지원
- 단일 접근 시 비정렬 이송 지원
- 제한 사항
  - 다중 Load Store 명령어 미지원
  - 스택 연산 PUSH POP 정렬 필수
  - 배타적 접근 Exclusive Access 정렬 필수
  - 비트 밴드 연산 비정렬 미지원

## Endian Mode
- Little Endian 권장 및 Big Endian 모두 지원
- 하위 바이트의 배치 방식 차이
  - Little Endian LSB가 낮은 주소에 저장
  - Big Endian MSB가 낮은 주소에 저장
