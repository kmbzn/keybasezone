## ARM Architecture Overview

## ARM
- 모바일 임베디드 프로세서 분야의 시장 리더
- 2020년 기준 1800억 개 이상의 ARM 기반 칩 출하
- ARM은 직접 반도체 실리콘을 제조하지 않음
  - IP 설계 라이선스 및 로열티 비즈니스 모델

## ARM Processor Architecture
- RISC Architecture 기반 임베디드 요구사항에 맞춘 확장
- 고정 길이 명령어
- Load-store architecture
  - Memory-to-register load 명령어
  - Register-to-memory store 명령어
- 대규모 균일 레지스터 파일
- 32-bit architecture v1-v7 64-bit architecture v8-v9
- 우수한 성능 및 전력 효율

## ARM Processor Family
- Application processors
  - MMU 지원, Linux 및 모바일 OS 실행
  - Cortex-A 시리즈
- Real time processors
  - 실시간 제어, 저지연 인터럽트
  - Cortex-R 시리즈
- Microcontrollers and deeply embedded
  - 최적화된 마이크로컨트롤러 시스템
  - Cortex-M 시리즈

## Processor Characteristics Summary
- Application Processors
  - High clock frequency, Long pipeline
  - High performance, Multimedia support NEON
  - Memory Management Unit MMU, Cache, TrustZone
  - 모바일 컴퓨팅, 스마트폰, 서버
- Real-time Processors
  - High clock frequency, Medium to long pipeline
  - Deterministic low interrupt latency
  - Memory Protection Unit MPU, Cache, TCM
  - 산업용 마이크로컨트롤러, 하드디스크 컨트롤러, 자동차
- Microcontroller Processors
  - Short pipeline, Ultra low power
  - Deterministic low interrupt latency
  - MPU, NVIC, WIC
  - 소형 임베디드, 센서, IoT, MEMS

## ARM Processors vs ARM Architectures
- ARM Architecture
  - 명령어 집합, 프로그래머 모델, 예외 모델, 메모리 맵 명세
  - Architecture Reference Manual 문서화
- ARM Processor
  - 특정 ARM 아키텍처를 기반으로 구현된 칩 설계
  - 타이밍 등 구체적 구현 상세 수록
  - Technical Reference Manual 문서화
- 예시 매핑
  - Armv6-M Cortex-M0, Cortex-M1
  - Armv7-M Cortex-M3
  - Armv7E-M Cortex-M4, Cortex-M7
  - Armv8-M Cortex-M23, Cortex-M33

## Instruction Sets
- ARM AArch32 32-bit 명령어
- Thumb 16-bit 명령어
- Thumb-2 16-bit 및 32-bit 혼합 가변 길이 명령어
  - Thumb 대비 약 25% 성능 향상
  - ARM 대비 약 26% 코드 크기 감소
- AArch64 64-bit 명령어

## Cortex-M Processor Overview

## Cortex-M Processor Family
- Cortex-M0
  - 초소형 초저전력 12K gates 시작
- Cortex-M0+
  - 최고 에너지 효율, 단일 사이클 I/O, 벡터 테이블 재배치
- Cortex-M1
  - FPGA 설계 최적화 소형 프로세서
- Cortex-M3
  - 하드웨어 나눗셈 및 MAC 지원 강력한 저전력 코어
- Cortex-M4
  - DSP 확장 SIMD 및 단정밀도 FPU 지원
- Cortex-M7
  - 고성능 임베디드, 캐시 및 TCM, 배정밀도 FPU 지원
- Cortex-M23
  - Cortex-M0+급 초저전력 및 TrustZone 보안 확장
- Cortex-M33
  - Cortex-M3 M4 계승 및 TrustZone 보안 확장

## Cortex-M3 Architecture Structure
- 계층 구조적 디자인
  - Cortex-M3 core Harvard architecture, 3단계 파이프라인
  - NVIC Configurable nested vector interrupt controller
  - Bus matrix ICode, DCode, System Bus
  - Debug components ETM 등
  - Optional MPU

## Programmer Model

## Cortex-M Programmer Model
- C 언어 완전 프로그래밍 가능
- 하드웨어 스택 기반 예외 모델
- Thumb 및 Thumb-2 명령어 집합 사용
- 두 가지 동작 모드
  - Thread Mode 사용자 태스크 실행
  - Handler Mode 예외 처리 실행
- 예외 핸들러 주소를 담은 Vector Table

## Registers of Cortex-M Processors
- R0-R7 Low registers 범용
- R8-R12 High registers
- R13 Stack Pointer SP
  - Main Stack Pointer MSP 커널 및 예외 처리용
  - Process Stack Pointer PSP 사용자 애플리케이션용
- R14 Link Register LR
- R15 Program Counter PC
- Special Registers
  - PSRs Program Status Registers APSR, IPSR, EPSR 또는 xPSR
  - PRIMASK, FAULTMASK, BASEPRI 인터럽트 마스크 레지스터
  - CONTROL 제어 레지스터
  - MRS 및 MSR 전용 명령어로만 접근 가능

## Operation Modes and Privilege Levels
- Privileged Level
  - Handler Mode 예외 처리 시
  - Thread Mode 메인 프로그램 실행 시 선택 가능
- Unprivileged Level User Level
  - Thread Mode 메인 프로그램 실행 시 선택 가능
- 모드 전환 과정
  - Reset 시 Privileged Thread Mode 진입
  - CONTROL 레지스터를 통해 Unprivileged Thread Mode 전환 가능
  - 예외 발생 시 Handler Mode 진입 및 처리가 끝나면 이전 모드로 복귀

## Vector Tables and Reset Sequence
- Vector Table
  - 각 예외 및 인터럽트 핸들러의 시작 주소를 담은 워드 배열
  - `0x00000000` 시작 주소에 초기 MSP 값 저장
  - `0x00000004` 시작 주소에 Reset vector 저장
- Reset 진행 과정
  1. `0x00000000`에서 초기 SP 값을 인출하여 R13 MSP에 로드
  2. `0x00000004`에서 Reset Vector를 인출하여 PC에 로드 LSB는 1로 설정되어 Thumb 상태 표기
  3. Reset Vector 주소의 첫 명령어를 인출하고 프로그램 실행 개시
