# 컬러 화면은 잠깐만: 흑백을 잊지 않게 해주는 MonoScreen

휴대폰 화면을 흑백으로 바꾸면 처음에는 조금 낯섭니다. 익숙하던 앱들이 갑자기 심심해 보이고, 손이 가는 횟수도 줄어드는 것 같습니다. 색으로 시선을 붙잡는 화면에서 한 발짝 물러나는, 작지만 분명한 변화입니다.

흔히 이런 시도를 **도파민 디톡스**라고 부릅니다. 거창한 치료법이라기보다는, 자극적인 화면과 알림에 무심코 반응하는 습관을 잠시 끊고 내가 무엇에 시간을 쓰는지 돌아보려는 생활의 실험에 가깝습니다. 흑백 화면은 그 실험을 시작하기 쉬운 방법 중 하나입니다.

그런데 매일 쓰다 보면 흑백만으로는 불편한 순간도 생깁니다. 지도를 볼 때 길을 구분하고 싶고, 카메라로 색을 확인해야 하며, 특정 앱을 쓸 때는 컬러가 필요합니다. 그래서 잠깐 흑백을 끕니다.

문제는 그다음입니다.

필요한 일을 마치고도 컬러 화면을 그대로 둡니다. 다시 흑백으로 바꾸는 걸 잊은 채 하루가 지나고, 어느 순간 휴대폰은 원래의 강한 색으로 돌아와 있습니다. 마음먹고 만든 규칙은 있었지만, 매번 기억해서 지키는 일은 생각보다 번거로웠습니다.

그래서 **MonoScreen**을 만들었습니다. 흑백을 켜는 의지를 더 단단히 다그치는 대신, 잠깐 풀어둔 설정을 휴대폰이 다시 챙겨주도록 해보자는 생각에서 출발했습니다.

## 흑백을 끄는 순간보다, 다시 켜는 순간을 자동으로

MonoScreen은 Android에서 동작하는 가벼운 백그라운드 서비스입니다. 화면이 꺼지거나 다시 켜질 때, 그리고 기기를 잠금 해제할 때 시스템의 흑백 설정을 다시 활성화합니다.

지도나 카메라처럼 컬러가 필요한 동안에는 빠른 설정에서 흑백을 잠시 꺼도 됩니다. 이때 화면을 쨍한 컬러로 완전히 되돌리는 대신, 채도를 절반 수준으로 낮춰 둡니다. 색 정보는 확인할 수 있지만, 화면 전체가 강한 색으로 가득 차는 느낌은 덜하도록 한 것입니다.

요약하면 사용 흐름은 단순합니다.

1. 평소에는 흑백 화면으로 사용합니다.
2. 컬러가 필요한 작업에서만 흑백을 잠시 끕니다.
3. 화면을 끄거나 켜고, 잠금 해제하는 과정에서 흑백이 다시 켜집니다.

완벽하게 휴대폰 사용을 통제해주는 도구는 아닙니다. 대신 “다시 켜야지”라는 작은 일을 기억에만 맡기지 않도록 돕습니다.

## 의지력 대신 작은 마찰을 줄이는 방법

디지털 디톡스는 휴대폰을 무조건 멀리하는 일이 아니라, 내가 원하지 않는 방식으로 화면을 열게 되는 순간을 알아차리는 데서 시작할 수 있습니다. 흑백 설정도 그 자체로 사용 습관을 바꾸어주지는 않습니다. 다만 화면이 주는 시각적 자극을 낮추고, 앱을 열기 전에 잠깐 멈출 계기를 만들어줄 수 있습니다.

저에게는 그 작은 장치가 꾸준함을 좌우했습니다. 색을 잠깐 쓰는 선택은 필요하지만, 매번 설정을 되돌리는 일을 잊지 않으려 애쓰는 건 다른 문제였습니다. MonoScreen은 컬러를 금지하기보다, 예외를 허용한 뒤 다시 원래의 선택으로 돌아가게 합니다.

대단한 자기관리 비법은 아닙니다. 그저 휴대폰을 내가 정한 방식으로 쓰기 위해 반복하던 일을 자동화한 것입니다. 때로는 의지를 더하는 것보다, 잊어버려도 괜찮은 구조를 만드는 편이 현실적이니까요.

## 설치는 조금 다릅니다

MonoScreen은 Android 시스템의 보안 설정을 변경해야 합니다. APK를 설치한 뒤 USB 디버깅이 가능한 컴퓨터에서 ADB로 `WRITE_SECURE_SETTINGS` 권한을 한 번 부여해야 합니다. README에는 화면 채도를 50%로 설정하는 명령과 서비스를 시작하는 방법도 안내되어 있습니다.

```sh
adb install -r app-debug.apk
adb shell pm grant com.custom.grayscaleauto android.permission.WRITE_SECURE_SETTINGS
adb shell cmd color_display set-saturation 50
adb shell am start -n com.custom.grayscaleauto/.MainActivity
```

시스템 설정을 바꾸는 권한이므로, 설치 전에 코드를 확인하고 본인이 신뢰하는 기기에서만 사용하세요. APK를 직접 빌드하거나 GitHub Actions에서 빌드 결과를 받는 방법은 프로젝트 저장소의 안내를 참고하면 됩니다.

흑백 화면이 모두에게 맞는 해답일 필요는 없습니다. 다만 컬러를 잠깐 썼다가 돌아오는 일을 자꾸 잊고 있었다면, 그 복귀를 자동화하는 것만으로도 하루의 화면은 조금 달라질 수 있습니다.
